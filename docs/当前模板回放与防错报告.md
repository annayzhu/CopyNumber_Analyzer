## 1. “32 孔”的正确结构

当前文件不是 32 个样本，而是：

- 8 个样本：Sample 1–Sample 8
- 每个样本 4 个物理孔
- 共 32 个已使用物理孔
- 仪器为 96-well block，只使用 A–H 的第 3、4、9、10 列
- multiplex 导出时每个 target 占一行，因此 32 孔展开成 80 条 assay 行

孔组合：

| 孔列 | 反应组合 | 每样本复孔 |
|---|---|---:|
| 3、4 | GSTT1 + RNaseP duplex | 2 |
| 9、10 | GSTM1 + GSTT1 + RNaseP triplex | 2 |

因为 GSTT1 同时出现在 duplex 和 triplex，分析器默认拆成两个 assay 层；加上 GSTM1 triplex，共 3 个 assay 层。如果确有桥接验证，用户可关闭“反应组合防混合”，将同一 target 的两种 panel 合并。

## 2. 原运行 Reference Sample 设置错误

文件 footer 记录：

- Endogenous Control = RNaseP
- Reference Sample = Sample 1

RNaseP 作为孔内归一化内参，这与 calibrator/reference sample 是两个不同概念。对 Sample 1 的 target 进行按 assay 审查后：

- **GSTM1**：两个 triplex 孔的 GSTM1 都是 Undetermined，而 RNaseP 有效。Sample 1 是 GSTM1 0-copy 候选，绝不能作为 GSTM1 的正拷贝数 calibrator。软件已禁止选择并双层拦截：界面选项禁用，计算核心再次验证。
- **GSTT1**：Sample 1 的 target 和 RNaseP 都有扩增，从本批 qPCR 质控角度是“校准候选样本”；但文件中没有 GSTT1 的已知拷贝数证据，所以软件不会自动使用。必须由用户输入 CN 并勾选“已由独立依据确认”。

这一设计使同一样本可能对一个 target 可作候选校准，对另一个 target 被禁止，不再存在“整板只有一个 Reference Sample”的危险自动继承。

## 4. 板级 HOLD 原因

分析器对当前文件输出 `HOLD · 不可放行`，主要原因是：

1. **仪器校准过期**：使用到的 FAM、CY5、VIC 纯染料校准均记录为 expired；Background、ROI、Uniformity 也记录为 expired。
2. **Ct threshold 设置**：文件记录 Automatic Ct Threshold = true；GSTM1/GSTT1 target threshold 约为 0.04，RNaseP 约为 0.193。经技术确认，自动 Ct threshold 为本实验室可接受设置，0.2 也不是强制值；因此工具不会因自动阈值或偏离 0.2 报警，仅保留同一 assay 内实际阈值不一致的检查。
3. **导出文件未识别到 NTC**：所有 Task 都是 `UNKNOWN`，样本名中没有 NTC。自 v1.1 起，该项保留为 warning，不再单独导致 `HOLD`，但必须人工记录无法排除污染的局限。若原始加样记录能证明某些现有孔确为无模板对照，仍可在分析工具中按样本名或物理孔人工补标；在没有实验记录确认时，程序不会自行把 Sample 8 或其他全 Undetermined 样本当作 NTC。
4. **仪器原始 flags 众多**：THOLDFAIL=48、CQCONF=38、NOAMP=11、EXPFAIL=35。`Amp Status=No Amp` 与 NOAMP flag 不是一一对应，所以程序保留每个 flag，不用任一单一 flag 代替 Ct + 内参 + 复孔综合判断。
5. **没有已知 target CN 字段**：文件只记录 Reference Sample = Sample 1，不包含 GSTM1/GSTT1 的独立已知 CN 证据。
6. **各 panel 只有 2 复孔**：讲义和快速指南推荐每样本 4 技术复孔。如不合并 duplex/triplex，每个 panel 仅 2 复孔，程序保留主计算但标记 `BELOW_RECOMMENDED_REPLICATES`。

## 5. 公式回放

为验证计算引擎，测试中明确关闭“反应组合防混合”，仅用于与原文件的 GSTT1 汇总 RQ 进行数值核对。将 Sample 1 作为 GSTT1 CN=2 的测试校准键时：

- Sample 1 mean ΔCt = -0.9709711075
- Sample 7 mean ΔCt = -0.2298083305
- ΔΔCt = 0.7411627769
- RQ = 2^(-0.7411627769) = 0.59825698
- 原文件 RQ = 0.59825701

两者在仪器浮点四舍五入范围内一致。这只验证ΔΔCt/RQ 代码正确，**不表示 Sample 1 的 GSTT1 CN=2 已被生物学确认**，也不表示 duplex 与 triplex 在方法学上已可合并。

## 6. 当前文件能与不能支持的结论

### 能支持

- 检查物理孔、样本、target、reporter、Ct、Amp Status 与 flags 的一致性。
- 区分内参失败、target 非零扩增、target 0-copy 证据和部分复孔扩增。
- 对非零拷贝样本重新计算孔级ΔCt、样本均值与 SD。
- 在用户提供并签认有效已知 CN calibrator 后，计算ΔΔCt、RQ 和连续 CN。

### 不能直接支持

- 不能仅凭这个文件证明哪个样本的 GSTM1 或 GSTT1 已知为 1/2 copies。
- 不能把 Sample 1 当作两个 target 共用的 calibrator。
- 不能将 Sample 8 报为双基因 0 copy。
- 不能仅凭 Sample 8 全部 Undetermined 就认定其为 NTC；人工补标必须来自原始加样记录。
- 不能在仪器校准过期、无 NTC 和无已知 CN 对照时放行正式拷贝数结论。
- 不能在每个相同 CN 类别样本数少于 7 时伪造可靠的 Confidence 和 |Z-score|。
